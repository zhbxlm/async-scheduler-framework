# 数据模型

## 核心模型

所有模型定义在 `async_scheduler/core/models.py`，持久化层在 `async_scheduler/persistence/models.py`。

---

## Task

任务是调度系统的基本执行单元。

```python
class Task(BaseModel):
    id: str                          # UUID
    name: str                        # 任务名称
    status: TaskStatus               # 当前状态
    payload: dict                    # 任务参数（含 capability 等）
    tenant_id: str | None            # 所属租户
    idempotency_key: str | None      # 幂等键
    priority: int                    # 优先级（越小越高，默认 0）
    scheduled_at: datetime | None    # 延时入队时间
    created_at: datetime
    updated_at: datetime
    started_at: datetime | None
    completed_at: datetime | None
    result: dict | None              # 执行结果
    error: str | None                # 错误信息
    retry_count: int                 # 已重试次数
    max_retries: int                 # 最大重试次数
    timeout_seconds: int             # 超时时间（秒）
```

### TaskStatus 枚举

| 值 | 含义 |
|----|------|
| `PENDING` | 已创建，等待入队 |
| `QUEUED` | 在优先级队列中等待消费 |
| `RUNNING` | 执行中（持有 lease） |
| `SUCCESS` | 成功完成 |
| `FAILED` | 执行失败（重试已耗尽） |
| `CANCELLED` | 已取消 |
| `TIMEOUT` | 执行超时 |
| `RETRY` | 等待重试 |

## ExecutionAttempt

记录每次任务执行的详细信息，一个 Task 可有多条 ExecutionAttempt。

```python
class ExecutionAttempt(BaseModel):
    id: str                              # UUID
    task_id: str                         # 关联任务 ID
    worker_id: str | None                # 执行 worker 标识
    retry_index: int                     # 第几次重试（0-based）
    status: ExecutionAttemptStatus       # 尝试状态
    lease_token: str | None              # 分布式 lease token
    started_at: datetime | None
    last_heartbeat_at: datetime | None   # 最后一次心跳时间
    completed_at: datetime | None
    error_message: str | None
```

### ExecutionAttemptStatus 枚举

| 值 | 含义 |
|----|------|
| `RUNNING` | 执行中，持有 lease |
| `SUCCEEDED` | 成功完成 |
| `FAILED` | 失败 |
| `ABANDONED` | 被 reconciler 标记为放弃（超时/崩溃） |
| `CANCELLED` | 被取消 |

## Schedule

Cron 定时调度定义。

```python
class Schedule(BaseModel):
    id: str
    name: str
    cron_expression: str             # 标准 cron 表达式，如 "*/5 * * * *"
    status: ScheduleStatus           # ACTIVE | PAUSED
    task_template: dict              # 触发时创建任务使用的 payload 模板
    dedup_window_seconds: int        # 去重窗口（同一窗口内不重复触发）
    tenant_id: str | None
    next_fire_at: datetime | None    # 下一次触发时间
    last_fired_at: datetime | None
    created_at: datetime
```

## DAG / DAGNode / DAGNodeExecution

```python
class DAGNode(BaseModel):
    id: str                          # 节点 ID（在 DAG 内唯一）
    task_type: str                   # 对应的 capability 名称
    depends_on: list[str]            # 依赖的其他节点 ID
    payload: dict                    # 节点参数
    condition: str | None            # 条件表达式（Python bool 字符串）
    on_skip: str | None              # 跳过时行为
    timeout_seconds: int             # 节点超时

class DAG(BaseModel):
    id: str
    name: str
    status: str                      # "pending" | "running" | "success" | "failed"
    nodes: list[DAGNode]
    node_executions: dict[str, DAGNodeExecution]  # 节点执行结果 map
    context: dict                    # DAG 全局上下文（节点间传递结果）
    tenant_id: str | None
    max_parallelism: int             # 最大并发节点数
    started_at: datetime | None
    completed_at: datetime | None

class DAGNodeExecution(BaseModel):
    node_id: str
    status: str                      # "pending" | "running" | "success" | "failed" | "skipped"
    skipped: bool
    result: dict | None
    error_message: str | None
    started_at: datetime | None
    completed_at: datetime | None
```

## WorkerInfo

Worker 注册信息（Redis 模式下使用）。

```python
class WorkerInfo(BaseModel):
    worker_id: str                   # 唯一标识（通常含 hostname + pid）
    name: str                        # 可读名称
    registered_at: float             # 注册时间戳
    last_heartbeat_at: float         # 最后心跳时间戳
    is_stale: bool                   # 是否已超时失联
```
