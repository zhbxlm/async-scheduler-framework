# 配额与多租户

## 概念

多租户系统允许多个团队（租户）共享同一个调度集群，通过配额隔离保证资源公平分配。

## 租户生命周期

```bash
# 创建租户
curl -X POST http://127.0.0.1:8000/tenants \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "team-a",
    "config": {
      "max_queued": 50,
      "max_running": 10
    }
  }'

# 列出所有租户
curl http://127.0.0.1:8000/tenants

# 查看租户详情
curl http://127.0.0.1:8000/tenants/{tenant_id}

# 更新配额
curl -X PATCH http://127.0.0.1:8000/tenants/{tenant_id} \
  -H 'Content-Type: application/json' \
  -d '{"config": {"max_queued": 100, "max_running": 20}}'
```

## 配额参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `max_queued` | 最大排队任务数 | 无限制 |
| `max_running` | 最大并发执行任务数 | 无限制 |

## 提交任务时指定租户

```bash
curl -X POST http://127.0.0.1:8000/tasks \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "team-task",
    "tenant_id": "tenant-a-uuid",
    "payload": {"capability": "echo"}
  }'
```

超出配额时返回：

```json
{
  "detail": {
    "error_code": "QUOTA_EXCEEDED",
    "message": "Tenant tenant-a has reached max_queued limit of 50"
  }
}
```

HTTP 状态码：`429 Too Many Requests`

## 查看配额使用

```bash
curl http://127.0.0.1:8000/quota/stats
```

```json
{
  "tenant-a": {
    "queued": 12,
    "running": 3,
    "max_queued": 50,
    "max_running": 10
  }
}
```

## 代码配置

```python
from async_scheduler.platform.quota import TenantQuotaManager

qm = TenantQuotaManager()

# 设置配额
qm.configure_tenant("tenant-a", max_queued=50, max_running=10)

# 手动检查（TaskRouter 内部自动调用）
try:
    qm.check_and_reserve("tenant-a", "queued")
except QuotaExceededError as e:
    print(f"配额超限: {e}")

# 任务完成后释放
qm.release("tenant-a", "running")
```

## 无租户场景

不指定 `tenant_id` 的任务归属于系统默认租户，不受配额限制（除非为 `None` 单独配置了配额）。
