# 节点代理（Node Agent）

## 当前状态

Node Agent / ClusterRegistry 是 deepwiki 分布式架构中管理计算节点的组件，在本仓库中**仅提供 ClusterRegistry 的基础骨架**。

## 已实现的内容

`ClusterRegistry`（`async_scheduler/platform/cluster_registry.py`）支持：
- 集群注册与查询
- 按 capability 查找支持该能力的集群
- 集群健康状态追踪（基础实现）

```bash
# 列出集群
curl http://127.0.0.1:8000/clusters

# 查询支持某 capability 的集群
curl http://127.0.0.1:8000/clusters/by-capability/video_encode

# 集群详情
curl http://127.0.0.1:8000/clusters/{cluster_id}
```
