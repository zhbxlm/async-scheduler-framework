# 项目概述

## 引言

`async-scheduler-framework` 是一个 **本地可运行、可扩展到分布式部署** 的异步任务调度框架。它以 deepwiki/ray-amu 的分布式调度设计为参考，提供了一套对齐其核心语义的轻量实现：FastAPI 任务 API、SQLite 持久化、可插拔 Backend 抽象层（支持内存和真实 Redis 两种后端），以及 DAG 编排、Cron 调度、多租户配额、分布式 Lease / Heartbeat / Reconciler 等能力。

## 定位

| 维度 | 说明 |
|------|------|
| 当前状态 | 已具备真实 Redis 关键共享状态路径，可用于单机多进程或小规模多节点部署 |
| 与 deepwiki 关系 | 设计启发下的 MVP 原型，已覆盖核心语义，尚未实现 Ray Actor/ResourceManager/NodeAgent 等 |
| 适用场景 | 二次开发基础、分布式调度语义学习、向生产级平台演进的起点 |

## 核心能力

- **FastAPI 任务 API**：任务 CRUD、批量创建、状态查询、执行历史
- **优先级队列与延时任务**：支持优先级调度和 `scheduled_at` 延时入队
- **DAG 编排引擎**：依赖解析、并行扇出、条件跳过、fallback、SSE 流式进度
- **Cron 定时调度**：基于 cron 表达式的调度注册表，支持 pause/resume
- **Backend 抽象层**：`QueueBackend` / `LockBackend` / `CompletionDedupBackend` / `RegistryBackend`，内存与 Redis 可切换
- **分布式 Lease**：`RedisLockBackend` 支持 acquire / extend / release / compare-and-act
- **Worker Registry**：worker 心跳注册、TTL 存活检测
- **TaskReconciler**：孤儿任务检测与自动修复（requeue / mark_failed）
- **多租户配额**：`TenantQuotaManager` 支持 max_queued / max_running 控制
- **Observability**：`/debug/summary`、`/debug/leases`、`/debug/leases/anomalies` 等排障端点

## 技术栈

| 组件 | 版本要求 | 用途 |
|------|---------|------|
| Python | ≥ 3.10 | 运行时 |
| FastAPI | ≥ 0.109 | HTTP API 框架 |
| SQLAlchemy | ≥ 2.0 | ORM + SQLite 持久化 |
| Pydantic | ≥ 2.0 | 数据模型与校验 |
| aioredis / redis-py | ≥ 4.x | Redis 异步客户端 |
| Click | ≥ 8.1 | CLI 入口 |
| croniter | ≥ 2.0 | Cron 表达式解析 |
| pytest + httpx | - | 测试套件 |

## 项目结构

```text
async_scheduler/
  api/           # FastAPI 应用（app.py）
  cli/           # CLI 入口（async-scheduler 命令）
  backends/      # Backend 抽象层 + 内存/Redis 实现
  core/          # 核心数据模型（Task / Schedule / DAG / ExecutionAttempt）
  dag/           # DAG 引擎 + step executors + loader
  executor/      # 任务执行器（超时 / 重试 / 取消）
  persistence/   # SQLAlchemy repositories
  platform/      # TaskRouter / TaskConsumer / TaskCompletionNode / TaskReconciler
                 # TenantQuotaManager / CapabilityRegistry / ServiceContainer
  queue/         # QueueManager（封装 Backend）
  registry/      # CapabilityRegistry
  scheduler/     # CronScheduler + ScheduleRegistry
  worker/        # Worker 抽象 + 示例 worker
  distributed/   # WorkerRegistry（Redis 心跳）
tests/           # pytest 单元 + 集成测试
scripts/         # smoke test / live Redis suite
examples/        # DAG 示例 + end-to-end demo
docs/            # 设计文档 + deepwiki 参考文档
```

## 架构概览

```
用户 / CLI
    │
    ▼
FastAPI (api/app.py)
    │
    ├── TaskRouter ──────────────────────────── TenantQuotaManager
    │       │                                         │
    │       ▼                                         │
    │   TaskRepository (SQLite)            CapabilityRegistry
    │       │
    │       ▼
    │   QueueManager (QueueBackend)
    │       │  InMemoryQueueBackend / RedisQueueBackend
    │       ▼
    │   TaskConsumer (background loop)
    │       │
    │       ├── LockBackend.acquire()   (distributed lease)
    │       ├── WorkerRegistry.register()
    │       └── TaskExecutor.execute()
    │               │
    │               ├── DAGEngine (if DAG task)
    │               └── CapabilityRegistry.dispatch()
    │
    ├── CronScheduler (background loop)
    │       └── ScheduleRegistry → enqueue tasks on trigger
    │
    ├── TaskReconciler (background loop)
    │       └── detect orphaned/stuck tasks → repair
    │
    └── TaskCompletionNode
            └── CompletionDedupBackend.claim_once() → idempotent finish
```
