# 队列管理

## 架构

队列系统基于 `QueueBackend` 抽象层，支持内存和 Redis 两种实现：

```
QueueManager
  └── QueueBackend
        ├── InMemoryQueueBackend  （默认，进程内 asyncio.PriorityQueue）
        └── RedisQueueBackend     （分布式，真实 Redis 数据结构）
```

## 队列类型

| 队列 | 说明 |
|------|------|
| ready queue | 待消费的普通任务（按优先级排序） |
| delayed queue | `scheduled_at` 未到期的任务，到时间后 promote 到 ready queue |
| per-capability queues | 按 capability 分桶的虚拟视图，用于统计 |

## 入队与出队

```python
from async_scheduler.backends import InMemoryQueueBackend

backend = InMemoryQueueBackend()

# 入队
await backend.enqueue(task_id, priority=0, payload={...})

# 延时入队
await backend.enqueue(task_id, priority=0, payload={...},
                      scheduled_at=datetime.utcnow() + timedelta(minutes=30))

# 出队（阻塞直到有任务）
item = await backend.dequeue(timeout=5.0)
if item:
    task_id, payload = item

# 取消（从队列中移除）
cancelled = await backend.cancel(task_id)

# 调整优先级
await backend.update_priority(task_id, new_priority=-1)
```

## Redis 队列（RedisQueueBackend）

Redis 队列使用以下数据结构：

| Key | 类型 | 用途 |
|-----|------|------|
| `scheduler:queue:ready` | Sorted Set | ready 队列，score = priority |
| `scheduler:queue:delayed` | Sorted Set | delayed 队列，score = timestamp |
| `scheduler:task:{id}` | Hash | 任务数据存储 |

关键操作使用 Lua 脚本保证原子性：
- `promote`：delayed → ready 的原子迁移
- `update_priority`：原子调整优先级（避免重复入队）
- `cancel`：原子从两个队列中移除

## 队列统计 API

```bash
# 总体队列统计
curl http://127.0.0.1:8000/queue/stats

# 列出所有 capability
curl http://127.0.0.1:8000/queues/capabilities

# 单 capability 统计
curl http://127.0.0.1:8000/queues/echo/stats
```

响应示例：

```json
{
  "queue_sizes": {
    "ready": 3,
    "delayed": 1
  },
  "total_queued": 3,
  "scheduled_count": 1,
  "running_tasks": 2,
  "worker_count": 1,
  "reconciler_running": true
}
```

## delayed queue promote 机制

`TaskConsumer` 在每次 dequeue 前自动检查 delayed queue 中到期的任务，将其 promote 到 ready queue：

```python
# 内部逻辑（简化）
due_tasks = await backend.peek_due(now=datetime.utcnow())
for task in due_tasks:
    await backend.promote(task.id)  # delayed → ready（原子操作）
```

## 内存模式 vs Redis 模式

| 特性 | InMemoryQueueBackend | RedisQueueBackend |
|------|---------------------|-------------------|
| 跨进程共享 | ❌ | ✅ |
| 持久化 | ❌（重启丢失） | ✅ |
| 原子操作 | asyncio 锁 | Lua 脚本 |
| 适用场景 | 单进程 / 开发测试 | 多进程 / 生产部署 |
