# 快速开始

## 环境要求

- Python ≥ 3.10
- pip（推荐 pip ≥ 23）
- （可选）Redis ≥ 6.0，用于分布式模式

## 安装

```bash
git clone https://github.com/zhbxlm/async-scheduler-framework.git
cd async-scheduler-framework
python3 -m pip install -e .[dev] --no-build-isolation
```

## 启动（内存模式，无需 Redis）

```bash
# 初始化数据库
async-scheduler init-db-cmd --force

# 启动 API + Worker + Cron + Reconciler
async-scheduler dev --init-db
```

打开 API 文档：
- Swagger UI：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/health

## 快速验证

```bash
# 1. 创建任务
curl -X POST http://127.0.0.1:8000/tasks \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "hello",
    "payload": {"capability": "echo", "message": "hello world"}
  }'

# 2. 查看队列状态
curl http://127.0.0.1:8000/queue/stats

# 3. 查看系统健康
curl http://127.0.0.1:8000/health
# → {"status": "healthy", "issues": [], "version": "1.0.0", "uptime_seconds": 12.3}

# 4. 运行全套冒烟测试
python -m scripts.smoke_test
```

## 启动（Redis 分布式模式）

```bash
# 本地启动 Redis（或使用已有 Redis）
redis-server &

# 以 Redis 模式启动
REDIS_URL=redis://localhost:6379/0 async-scheduler dev --init-db
```

或通过代码配置：

```python
from async_scheduler.backends import BackendConfig
from async_scheduler.platform import build_service_container

config = BackendConfig(
    distributed_mode=True,
    queue_type="redis",
    lock_type="redis",
    redis_url="redis://localhost:6379/0",
    lease_ttl_seconds=30,
    heartbeat_interval_seconds=10,
)
services = await build_service_container(backend_config=config)
```

## CLI 常用命令

```bash
# 创建任务
async-scheduler task demo --payload '{"capability":"echo","message":"hello"}'

# 创建定时调度
async-scheduler schedule heartbeat '*/5 * * * *' \
  --payload '{"capability":"echo","message":"tick"}'

# 查看运行状态
async-scheduler status

# 手动触发 reconciler
async-scheduler reconcile
```

## 运行测试

```bash
# 全量单元测试
pytest -q

# 冒烟测试（基础框架验证）
python -m scripts.smoke_test

# Live Redis 集成测试（需要运行中的 Redis）
TEST_REDIS_URL=redis://localhost:6379/0 python3 scripts/live_redis_suite.py

# 分布式协调 smoke
python3 scripts/distributed_smoke_test.py
```
