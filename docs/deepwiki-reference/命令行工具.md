# 命令行工具

`async-scheduler` CLI 由 `async_scheduler/cli/main.py` 提供，基于 Click 框架。

## 安装后可用命令

```bash
async-scheduler --help
```

## 常用命令

### 启动 API 服务

```bash
async-scheduler api [--host 127.0.0.1] [--port 8000] [--init-db]
```

### 启动开发模式（API + Worker + Cron + Reconciler）

```bash
async-scheduler dev [--init-db]
```

### 初始化数据库

```bash
async-scheduler init-db-cmd [--force]
```

`--force` 会删除并重建所有表，用于重置测试环境。

### 创建任务

```bash
async-scheduler task demo \
  --payload '{"capability":"echo","message":"hello"}'
```

### 创建定时调度

```bash
async-scheduler schedule heartbeat '*/5 * * * *' \
  --payload '{"capability":"echo","message":"tick"}'
```

### 查看运行状态

```bash
async-scheduler status
```

输出示例：

```
Async Scheduler Status
======================
API: http://127.0.0.1:8000
Health: healthy
Consumer: running
Scheduler: running
Reconciler: running
Queue size: 0
Workers: 1
```

### 手动触发 Reconciler

```bash
async-scheduler reconcile
```

## 环境变量

CLI 会读取以下环境变量：

```bash
REDIS_URL=redis://localhost:6379/0 async-scheduler dev --init-db
DATABASE_URL=sqlite+aiosqlite:///./custom.db async-scheduler api
LOG_LEVEL=DEBUG async-scheduler dev
```
