# 异步代理（Async Proxy）

## 当前状态

Async Proxy Sidecar 是 deepwiki 对齐路线图中的高级组件，在本仓库中**仅有接口骨架，尚未实现完整功能**。

## 概念

Async Proxy 作为任务执行的 sidecar，负责：
- 代理任务 handler 的异步调用
- 在 worker 崩溃时保留执行上下文
- 支持长时任务的状态外包（offloading）

## 当前可用的 API 端点

```bash
# 查看 Async Proxy 统计（未配置时返回 404）
curl http://127.0.0.1:8000/async-proxy/stats
```

## 配置

当 `ServiceContainer` 中 `async_proxy_sidecar` 不为 `None` 时，端点才生效。当前版本需手动在 `build_service_container()` 中注入实现。
